# Designer Social Media

Designer Social Media is a front-end prototype of a social networking platform, focusing on user interface design and interactivity. Built with HTML, CSS, and JavaScript, it showcases various components commonly found in social media applications.

## Features

* **User Registration**: Interactive registration form with client-side validation.
* **Forum Page**: Structured layout for user posts and discussions.
* **Notifications**: Dynamic notification panel to keep users informed.
* **Avatar Collection**: Gallery of user avatars with selection functionality.
* **Responsive Design**: Optimized for various screen sizes and devices.

## Technologies Used

* HTML5
* CSS3
* JavaScript([GitHub][1])

## Getting Started

To view and interact with the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/AnVu1408/Designer-Social-Media.git
   ```


2\. Navigate to the project directory:

```bash
cd Designer-Social-Media
```


3\. Open the desired HTML file (e.g., `register.html`, `forum.html`) in your web browser.
